# 🚀 Proyecto 02: Landing Page B2B (Nexcent Clone)

## 📖 Descripción General
Este proyecto es una Landing Page estática enfocada en replicar un diseño profesional para un SaaS B2B de gestión de comunidades. El objetivo es demostrar un dominioavanzado en la creación de interfaces de usuario (UI), componentización y diseño "pixel-percect" utilizando metodologías modernas.

## 🎯 Alcance del MVP
El proyecto se considerará terminado cuando refleje fielmente el diseño de Figma proporcionado, cumpliendo con:
* **Pixel-Perfect UI:** Tipografía, espaciados y paleta de colores extraídos directamente del diseño original.
* **Responsive Design (Mobile First):** Adaptación fluida del layout de escritorio a dispositivos móviles.
* **Componentización:** Uso de `props` para elementos repetitivos (tarjetas de servicios, estadísticas, artículos de blog).

## 🛠️ Stack Tecnológico
* **Core:** React 18 (Vite).
* **Lenguaje:** TypeScript (Tipado estricto).
* **Estilizado:** Tailwind CSS.
* **Econografía:** Lucide React o Heroicons.

## 🧩 Estructura de Componentes Clave
1. `Navbar` y `Footer` (Extremos).
2. `Hero` (Sección principal con ilustración).
3. `ClientLogos` (Carrusel/Grid de clientes).
4. `FeatureCard` (Componente reutilizable para las características).
5. `SplitSection` (Componente de texto e imagen alternada).
6. `Stats` (Grid de números e íconos).
